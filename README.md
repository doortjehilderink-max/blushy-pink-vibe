# BlushLuxe Finds

Bouw BlushLuxe: een mobile-first, roze Pinterest-achtige community-app. Gebruikers kunnen accounts maken, posts/foto’s uploaden, zoeken, hartjes geven, en sterren plus reviews schrijven. Sterren en reviews mogen alleen door ingelogde gebruikers worden geplaatst. Gebruik Lovable Cloud voor authenticatie, opgeslagen content, reviews en bestandsuploads. Maak het als installeerbare mobiele webapp/PWA, met een verfijnde luxe roze uitstraling.

This project was built with [Lovable](https://lovable.dev).
